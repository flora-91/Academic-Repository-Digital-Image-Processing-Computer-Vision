# 🖼 Digital Image Processing & Computer Vision

### Academic Repository | Image Processing, Computer Vision, VLMs & Agentic AI

This repository contains the practical work, laboratory exercises, and projects developed during the **Digital Image Processing, Computer Vision, Vision Language Models (VLMs), and Agentic AI** course as part of the **Higher Technical Degree in Data Science & Artificial Intelligence**.

The repository covers the complete learning path, from the fundamentals of image processing to computer vision techniques and modern AI-based vision models.

---

The repository includes practical exercises and notebooks covering:

- Digital Image Processing
- Computer Vision
- Image Enhancement
- Image Segmentation
- Geometric Transformations

- Object Detection
- Contour Analysis
- OpenCV
- NumPy
